# Cerios Clinic — Starten

Zo start je de Cerios Clinic test applicatie lokaal.

1. **Start Docker Desktop.** Het kan helpen om Docker Desktop van tevoren alvast op te starten.

2. **Voer de Quick Start uit.** Ga naar <https://github.com/CeriosTesting/cerios-clinic> en voer de
   stappen uit onder **Quick Start (pre-built images — no clone needed)**. Kies daarbij de commando's
   voor jouw OS.

   Je kunt de commando's uitvoeren:
   - los in een **PowerShell** venster, of
   - in de terminal van **VS Code** (**Terminal -> New Terminal**)
