Playwright

Wie is de toneelschrijver?

Sinds januari 2020 voor het eerst aangekondigd door Microsoft. Gemaakt door een team dat eerder aan soortgelijke projecten werkte, bijvoorbeeld Puppeteer van Google.

  • Open source
  • Een library, geen framework
  • Node.js, Python, Java en .NET
